# Iğdır Korsan Taksi

Iğdır korsan taksi dört ilçeli küçük bir hatta çalışır ama sınır trafiği işi büyütür. Şehit Bülent Aydın Havalimanı merkezden 18 kilometre, 14 dakika uzaklıktadır. Aralık üzerinden Dilucu Sınır Kapısı'na gidenler için yol havalimanından 66 kilometre ilerisidir.

Nahçıvan'a geçecek tüccar Dilucu'ya, dağcı ve gezgin Doğubayazıt üzerinden Ağrı Dağı eteğine gider. Tuzluca'daki tuz mağaraları için günübirlik sefer istenir; Tuzluca havalimanına 28 kilometre, 25 dakikadır.
